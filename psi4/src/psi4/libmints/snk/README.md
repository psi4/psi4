# Generated 3c1e integral kernels

`BatchedPotentialInt` evaluates shell pairs of angular momenta 0 to 3 with
Obara-Saika vertical-recurrence kernels generated by
[snk_integral_codegen](https://github.com/jesse-dicenso/snk_integral_codegen),
the kernel generator of

J. DiCenso, H. Laqua and M. Head-Gordon, "Vectorized and Symbolically Optimized
Seminumerical Exchange for Large-Scale Quantum Chemistry", arXiv:2610.21075 (2026).

- `codegen/`: the generator, unmodified, at commit
  f15df00115301fefbb4380ca336775622f18a16b (MIT license, see `codegen/LICENSE`).
- `generate.py`: runs it and writes everything else in this directory: the
  kernels `VRR_*.C` and `VRR_*.h` (`_SAMECENTER` for shells on the same center),
  `snk_kernels.cc`, which compiles them, and `snk_kernels.h`, their dispatch
  tables. Do not edit those files by hand.

Each kernel evaluates the vertical recurrence for one pair of shell angular
momenta over a batch of grid points, from Obara-Saika seed integrals
(2 pi / p) U_p F_N(T) supplied by the caller, accumulating over the primitive
pairs. Only am(A) >= am(B) is generated: at the commit above, the generator
emits uncompilable code for an s shell on A with a higher shell on B (P - A is
used but not declared). `BatchedPotentialInt` transposes the other orders.

## Regenerating

With SymPy installed (these files were generated with SymPy 1.14 under Python
3.15):

```
python psi4/src/psi4/libmints/snk/generate.py
```
